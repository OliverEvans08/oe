3D Engine in Java Details

GameEngine

At first, I wasn't sure why I chose this project, but I was looking for something that would keep me learning and improving over time. I decided to build a 3D engine in Java without relying on any external libraries—just math and Swing 2D. Core Components

The engine consists of several key classes that handle various aspects of the 3D world:

Camera Class

The Camera class is responsible for the position, orientation, and movement of the camera in the 3D world. The camera’s update method handles movement based on keyboard input: 


public void update(double delta) {
    if (keyboard.isKeyDown(KeyEvent.VK_W)) {
        x += Math.cos(yaw) * speed * delta;
        z += Math.sin(yaw) * speed * delta;
    }
    if (keyboard.isKeyDown(KeyEvent.VK_S)) {
        x -= Math.cos(yaw) * speed * delta;
        z -= Math.sin(yaw) * speed * delta;
    }
}

This logic updates the camera’s position when the "W" or "S" keys are pressed, moving the camera in the 3D space based on its current orientation (yaw).

Renderer Class

The Renderer class handles the transformation of vertices and the drawing of objects in the scene. A key optimization in this class is caching values like trigonometric values for yaw and pitch to avoid unnecessary recalculations: 


private void updateTrigonometricValues() {
    cachedYaw = camera.yaw;
    cachedPitch = camera.pitch;
    cachedCosYaw = Math.cos(cachedYaw);
    cachedSinYaw = Math.sin(cachedYaw);
    cachedCosPitch = Math.cos(cachedPitch);
    cachedSinPitch = Math.sin(cachedPitch);
    valuesCached = true;
}

The drawWireframeGameObject method is responsible for rendering objects in wireframe mode: 


private void drawWireframeGameObject(Graphics2D g2d, GameObject gameObject, double[][] vertices, int[][] edges, int width, int height, double cameraHeight) {
    g2d.setColor(gameObject.getColor());
    for (int[] edge : edges) {
        double[] v1 = vertices[edge[0]];
        double[] v2 = vertices[edge[1]];
        int[] p1 = project(v1, width, height, cameraHeight);
        int[] p2 = project(v2, width, height, cameraHeight);
        g2d.drawLine(p1[0], p1[1], p2[0], p2[1]);
    }
}

This method draws each edge between vertices of a game object on the screen using 2D lines, creating a wireframe effect.

GameObject Class

The GameObject class represents an object in the 3D world. It manages transformation (position, rotation, scaling) and the hierarchical structure of objects (parent-child relationships). A key method in this class is getWorldTransform, which calculates the object's world transformation based on its parent’s transformation: 


public Matrix4 getWorldTransform() {
    if (parent != null) {
        return parent.getWorldTransform().multiply(transform.getTransformationMatrix());
    }
    return transform.getTransformationMatrix();
}

This logic ensures that the world transformation is recursively applied, considering the parent-child relationships in the object hierarchy.

Additionally, the getTransformedVertices method applies the transformation matrix to the object’s vertices: 


public double[][] getTransformedVertices() {
    double[][] originalVertices = getVertices();
    double[][] transformedVertices = new double[originalVertices.length][3];

    for (int i = 0; i < originalVertices.length; i++) {
        Vector3 vertex = new Vector3(originalVertices[i][0], originalVertices[i][1], originalVertices[i][2]);
        Vector3 transformed = transform.getTransformationMatrix().transform(vertex);

        transformedVertices[i][0] = transformed.x;
        transformedVertices[i][1] = transformed.y;
        transformedVertices[i][2] = transformed.z;
    }

    return transformedVertices;
}

This method ensures that all vertices are properly transformed and ready for rendering.

Object Simplification

To optimize performance, the Renderer simplifies object vertices based on their distance from the camera. This reduces the precision of distant objects, improving render speed: 


private double[][] simplifyVertices(double[][] vertices, double distance) {
    int precision = (int) Math.max(1, Math.min(4, Math.log10(distance) - 1));
    return simplifyVerticesByPrecision(vertices, precision);
}

This method adjusts the level of detail for objects based on how far they are from the camera, ensuring efficient rendering.

Renderer's Projection

The project method is responsible for projecting 3D vertices into 2D screen space: 


private int[] project(double[] v, int width, int height, double cameraHeight) {
    double vx = v[0] - camera.x;
    double vy = v[1] - (camera.y + cameraHeight);
    double vz = v[2] - camera.z;

    double x = vx * cachedCosYaw + vz * cachedSinYaw;
    double z = -vx * cachedSinYaw + vz * cachedCosYaw;

    double y = vy * cachedCosPitch + z * cachedSinPitch;
    double depthZ = -vy * cachedSinPitch + z * cachedCosPitch;

    depthZ = Math.max(depthZ, Float.MIN_VALUE);

    double invZ = gameEngine.clickGUI.getFOVSlider().getValue() / depthZ;
    int screenX = (int) (x * invZ + width / 2);
    int screenY = (int) (-y * invZ + height / 2);

    return new int[]{screenX, screenY};
}

This method uses the camera's orientation and position to project the 3D world onto the 2D screen space, creating the illusion of depth.

Lane Detection Pipeline

The core of the lane detection process, this function applies several computer vision techniques to extract road lanes from the captured image:

  • Convert to Grayscale – Removes color information to simplify processing.
  • Apply Gaussian Blur – Reduces noise and smooths the image.
  • Canny Edge Detection – Identifies strong edges in the image, highlighting potential lane markings.
  • Region of Interest Masking – Focuses processing on the road by filtering out irrelevant parts of the image.
  • Hough Line Transform – Detects lane lines by identifying straight-line segments in the processed image.
  • Lane Drawing – The detected lane lines are separated into left and right lanes, then drawn onto the frame.

private BufferedImage scan(BufferedImage image) {
    Mat frame = bufferedImageToMat(image);
    Imgproc.cvtColor(frame, gray, Imgproc.COLOR_BGR2GRAY);
    Imgproc.GaussianBlur(gray, blur, new Size(5, 5), 0);
    Imgproc.Canny(blur, edges, 100, 200);
    Core.bitwise_and(edges, mask, roiEdges);
    Imgproc.HoughLinesP(roiEdges, lines, 1, Math.PI / 180, 50, 30, 10);
    drawLane(result, leftLines, new Scalar(255, 0, 0)); // Blue for left lane
    drawLane(result, rightLines, new Scalar(0, 255, 0)); // Green for right lane
    return matToBufferedImage(result);
}

Drawing Lanes

Once the lane lines are detected, they need to be drawn onto the image. This function ensures that:

  • The detected lines are filtered and grouped into left and right lanes.
  • A polynomial fitting technique is used to estimate smooth lane curves.
  • The final lanes are drawn onto the processed image using OpenCV's Imgproc.line function.

private void drawLane(Mat frame, java.util.Listdouble lines, Scalar color) {
    if (lines.isEmpty()) return;
    MatOfPoint matPoints = new MatOfPoint(points.toArray(new Point[0]));
    Imgproc.fitLine(matPoints, lineParams, Imgproc.DIST_L2, 0, 0.01, 0.01);
    Imgproc.line(frame, new Point(xStart, yStart), new Point(xEnd, yEnd), color, 5);
}
